
## Pokemon CLI

I built a command-line tool to get the weight, height, or type of a Pokémon. It also compares two Pokémon's weights and includes two flags, --raw and --word, that control how it displays the information.
Learned how to add arguments in subcommands and add a mutually exclusive group.

## How to install

> pip install -i https://test.pypi.org/simple/ --extra-index-url https://pypi.org/simple/ resolution-week2-aryanjain23
